# LUMEN — живые обои для Windows

Интерактивные живые обои: снег ложится на ваши иконки, в море ловится рыба, в Backrooms курсор становится фонариком, а во Frutiger Aero можно выдувать мыльные пузыри.

**Сайт:** https://lumen-oboi.vercel.app
**Скачать:** [последний релиз](https://github.com/isabekdanial33-gif/lumen-wallpapers/releases/latest)

Windows 10/11, x64.
